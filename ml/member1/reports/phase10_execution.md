# Member 1 — Model Experiment Execution

Candidate models are executed on the Phase 7 training split using stratified 5-fold cross-validation. Each model is wrapped with the disease-specific preprocessing pipeline, preventing preprocessing leakage between folds. The untouched test set is not used for comparison or tuning.

Metrics: Accuracy, Precision, Recall, F1 and ROC-AUC for Heart Disease and Diabetes. Stroke additionally records PR-AUC / Average Precision because of severe class imbalance.

Result CSV files are generated by executing the disease-specific experiment scripts; no estimated metric values are entered manually. Final model selection and test-set evaluation remain later steps.
