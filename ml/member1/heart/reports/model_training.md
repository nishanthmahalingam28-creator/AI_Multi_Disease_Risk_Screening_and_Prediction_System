# Heart Disease — Multiple Model Training

Phase 10 starts the candidate-model comparison.

Candidates:
- Logistic Regression
- Support Vector Machine
- Random Forest
- Gradient Boosting
- XGBoost when the dependency is available

Each candidate is evaluated through a pipeline containing the Heart preprocessing transformer. Cross-validation uses stratified 5-fold validation on the training set only.

No final model is selected in this phase. Actual metric values must be generated by executing the experiment runner and saved from the experiment output.
